# ⚡ Snapdragon Local Text Processing Assistant

An **on-device, privacy-first Natural Language Processing (NLP) utility** built for Snapdragon-powered PCs. It performs document summarization, key phrase extraction, and text analytics locally without sending data to the cloud.

---

## 🌟 Features
* 🔒 **100% Privacy-First:** All text processing happens locally on your machine.
* ⚡ **On-Device Efficiency:** Optimized layout and execution designed for local hardware execution.
* 📝 **Instant Summarization:** Generates quick summaries of pasted documents and notes.
* 📌 **Keyword Extraction:** Automatically identifies and counts top keywords.
* 📊 **Text Metrics:** Tracks word and sentence counts instantly.

---

## 🛠️ Tech Stack
* **Language:** Python 3.14
* **Backend:** Native HTTP Server (`http.server`, `socketserver`)
* **Text Analytics:** Regular Expressions (`re`), Python Standard Collections (`Counter`)
* **UI/UX:** HTML5, CSS3 (Snapdragon Dark Mode Theme)
